# OREN Pterodactyl Installer v1
Interactive nested-category Linux management suite for Pterodactyl/Nodes/Wings.

Run as root:
```bash
chmod +x install.sh
sudo ./install.sh
```

Categories: Panel, Nodes & Wings, Runtime/Languages, Database, Web Server, Docker, Security, Backup, Maintenance, Diagnostics, Optimization, Advanced Tools.

Installer log: `/var/log/oren-pterodactyl/installer.log`
